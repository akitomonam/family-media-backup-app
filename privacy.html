プライバシーポリシー

Family Media Backup（以下「本ツール」）は、開発者本人が自分の Google アカウントでのみ使う個人用ツールです。

取得する情報と使い道

  • YouTube（https://www.googleapis.com/auth/youtube）：自分の動画を自分のチャンネルへ非公開でアップロードし、再生リストに追加するために使います。
  • Gmail 送信（https://www.googleapis.com/auth/gmail.send）：実行結果の通知メールを自分宛てに送るためだけに使います。メールの読み取りはしません。

保存と共有

認証情報とアップロードの記録は、本ツールを動かしているコンピューターの中にだけ保存します。第三者への提供や販売はしません。広告や分析には使いません。

本ツールによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

アクセスの取り消し

Google アカウントのアクセス設定から、いつでも本ツールのアクセスを取り消せます。
